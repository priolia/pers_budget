# 💰 Budget App v2.0 - Приложение для управления личным бюджетом

## 🎯 О проекте

Budget App v2.0 - это полный рефакторинг приложения для управления личными финансами с исправлением критических багов и добавлением нового функционала.

## ⭐ Что нового в v2.0?

### Критические исправления

- ✅ **Исправлена потеря данных при фильтрации** - траты больше не теряются при применении фильтров
- ✅ **Исправлено сохранение категорий** - изменения категорий теперь сохраняются корректно
- ✅ **Автоматические бэкапы** - каждое изменение создает резервную копию
- ✅ **Разделение данных и настроек** - пароль больше не хранится вместе с данными

### Новый функционал

- 📥 **Импорт данных** - возможность восстановить данные из файла экспорта
- 📅 **Кастомный период** - можно настроить любой день начала отчетного периода (не только 1-е число)
- 🔄 **Умная синхронизация** - двусторонняя синхронизация с разрешением конфликтов по timestamp
- 🏷️ **Уникальные ID** - каждая категория и трата имеет уникальный ID
- 📊 **Улучшенная вкладка настроек** - удобное управление всеми параметрами

### Архитектурные улучшения

- 🗂️ **Модульная структура** - код разделен на логические модули
- 📦 **ES6 Modules** - современный подход к организации кода
- 🎨 **Разделение HTML/CSS/JS** - чистая архитектура
- 🔧 **Легкая поддержка** - простота добавления нового функционала

## 🚀 Быстрый старт

### 1. Установка

Следуйте подробной инструкции в файле **[ИНСТРУКЦИЯ_ПО_УСТАНОВКЕ_V2.md](./ИНСТРУКЦИЯ_ПО_УСТАНОВКЕ_V2.md)**

### 2. Настройка

1. Обновите настройки в `js/config.js`:
   ```javascript
   API: {
       BASE_URL: 'https://ваш-сервер.com/api',
       KEY: 'ваш-api-ключ',
       USE_API: true
   }
   ```

2. Запустите API сервер:
   ```bash
   cd budget_api
   python3 app_v2.py
   ```

3. Откройте приложение в браузере

### 3. Миграция данных

После установки обязательно выполните миграцию:

```javascript
// В консоли браузера (F12)
await BudgetApp.migrate()
```

## 🔧 Использование

### Через интерфейс

Все функции доступны через вкладки приложения:
- **Справочник** - просмотр категорий и их лимитов
- **Траты** - добавление и редактирование трат
- **Категории** - управление категориями
- **Бюджет** - сводка и графики
- **Настройки** - все настройки приложения

### Через консоль браузера

Откройте консоль (`F12`) и используйте глобальный объект `BudgetApp`:

```javascript
// Статистика
BudgetApp.showInfo()

// Синхронизация
await BudgetApp.sync()

// Экспорт
BudgetApp.exportData()

// Импорт
await BudgetApp.importData()

// Обновление курсов
await BudgetApp.updateRates()

// Миграция
await BudgetApp.migrate()
```

### Работа с данными

```javascript
// Получить все категории
const categories = BudgetApp.DataManager.getCategories()

// Получить категорию по ID
const cat = BudgetApp.DataManager.getCategoryById('cat_xxx')

// Добавить категорию
BudgetApp.DataManager.addCategory({
    name: 'Новая категория',
    limit: 500,
    percentage: 15
})

// Обновить категорию
BudgetApp.DataManager.updateCategory('cat_xxx', {
    limit: 600
})

// Получить все траты
const expenses = BudgetApp.DataManager.getExpenses()

// Добавить трату
BudgetApp.DataManager.addExpense({
    categoryId: 'cat_xxx',
    amount: 100,
    currency: 'EUR',
    description: 'Покупка'
})

// Сохранить изменения на сервер
await BudgetApp.saveData()
```

## 🔄 API Endpoints

### v2.0 Endpoints

- `GET /api/health` - Проверка работоспособности
- `GET /api/categories` - Получить категории
- `POST /api/categories` - Сохранить категории
- `GET /api/expenses` - Получить траты
- `POST /api/expenses` - Сохранить траты
- `GET /api/config` - Получить конфигурацию
- `POST /api/config` - Сохранить конфигурацию
- `GET /api/export` - Экспорт всех данных
- `GET /api/backups` - Список бэкапов

### Legacy Endpoints (обратная совместимость)

- `GET /api/data` - Получить все данные (legacy формат)
- `POST /api/data` - Сохранить все данные (legacy формат)

## 🔐 Безопасность

- Пароль хранится в виде SHA-256 хеша
- Пароль НЕ экспортируется при экспорте данных
- Все запросы к API требуют API ключ
- Бэкапы создаются автоматически перед каждым изменением
- Старые бэкапы удаляются через 30 дней

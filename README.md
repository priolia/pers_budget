## 🎯 О проекте

**Персональное бюджетирование v2.0** — это современное веб-приложение для эффективного управления личными финансами с поддержкой:

- 🌍 **Нескольких валют** (EUR, UAH, BGN)
- ☁️ **Серверного хранения** данных с автоматической синхронизацией
- 💾 **Оффлайн режима** с локальным сохранением
- 📊 **Визуализации бюджета** с помощью интерактивных графиков
- 🔐 **Защиты данных** паролем (SHA-256 хеширование)
- 💱 **Автоматического обновления** курсов валют (Monobank API + резервный источник)
- 🔍 **Фильтрации расходов** по категориям и периодам

### ✨ Ключевые преимущества

- **Не потеряете данные** — автоматическое сохранение на сервер и резервное копирование
- **Работает везде** — доступ с любого устройства через браузер
- **Работает оффлайн** — продолжайте работать даже без интернета
- **Простота** — всё в одном интерфейсе, никаких сложных настроек
- **Безопасность** — данные защищены паролем и API ключом

## 🎨 Возможности

### 📊 Управление бюджетом
- ✅ Настройка месячного дохода и категорий расходов
- ✅ Установка лимитов в евро или процентах от дохода
- ✅ Автоматический расчёт лимитов в гривнах и левах
- ✅ Визуализация плана vs. факта на интерактивном графике (Chart.js)
- ✅ Цветовая индикация превышения лимитов (🟢/🟡/🔴)

### 💸 Учёт расходов
- ✅ Быстрое добавление трат с указанием даты, времени, категории и суммы
- ✅ Поддержка трёх валют: EUR, UAH, BGN
- ✅ Автоматическая конвертация по актуальным курсам
- ✅ **Фильтрация по категориям** — просмотр расходов по выбранным категориям
- ✅ Фильтрация по периодам (месяц/год)
- ✅ Редактирование и удаление расходов

### 💱 Курсы валют
- ✅ **Автоматическое обновление через Monobank API** (основной источник для UAH)
- ✅ Резервный источник данных (ExchangeRate-API)
- ✅ Актуальные курсы от украинского банка (обновление каждые 5 минут)
- ✅ Ручное редактирование курсов при необходимости
- ✅ Отображение времени последнего обновления и источника данных
- ✅ Кнопка быстрого обновления курсов

### 🔐 Безопасность и управление паролем
- ✅ Вход по паролю (SHA-256 хеширование)
- ✅ **Смена пароля** из интерфейса приложения
- ✅ **Утилита для генерации хеша пароля** ([docs/tools/hash-password.html](docs/tools/hash-password.html))
- ✅ **Утилита для диагностики и сброса пароля** ([docs/tools/reset-password.html](docs/tools/reset-password.html))
- ✅ Защита API ключом
- ✅ CORS для ограничения доступа

### 📤 Экспорт данных
- ✅ Экспорт расходов за период в JSON
- ✅ Экспорт всех данных одним файлом
- ✅ Автоматические резервные копии на сервере

### ☁️ Серверная синхронизация
- ✅ Автоматическое сохранение данных на сервер
- ✅ Доступ к данным с любого устройства
- ✅ **Индикатор статуса подключения** (🟢 онлайн / ⚠️ проблемы / 💾 оффлайн)
- ✅ Работа в оффлайн режиме с локальным хранением

## 🛠️ Технологии

### Frontend
- **HTML5** — структура приложения
- **CSS3** — адаптивный дизайн и стилизация
- **JavaScript (ES6+)** — логика приложения
- **Chart.js** — графики и визуализация
- **LocalStorage API** — локальное хранение данных
- **Fetch API** — взаимодействие с сервером

### Backend
- **Python 3** — серверная логика
- **Flask** — веб-фреймворк для API
- **Flask-CORS** — настройка CORS
- **python-dotenv** — управление переменными окружения

### Infrastructure
- **GitHub Pages** — хостинг frontend приложения
- **VPS** — сервер для API
- **Nginx** — reverse proxy и SSL termination
- **Let's Encrypt** — бесплатные SSL сертификаты
- **DuckDNS** — бесплатный динамический DNS
- **Systemd** — управление сервисом API

### Безопасность
- **SHA-256** — хеширование паролей
- **HTTPS/TLS** — шифрование данных
- **API Key** — аутентификация запросов
- **CORS** — ограничение источников запросов

## 📖 Использование

### Первый запуск

1. **Откройте приложение** в браузере
2. **Войдите с паролем** `1234` (пароль по умолчанию)
3. **Обязательно смените пароль** в разделе "Настройки"

### Настройка бюджета

1. Перейдите на вкладку **"Справочник"**
2. Укажите ваш **доход в евро**
3. Настройте **лимиты ФОП и крипто** (если применимо)
4. Отредактируйте **категории расходов**:
   - Измените существующие категории
   - Добавьте новые через кнопку "Добавить категорию"
   - Укажите лимиты в EUR или в % от дохода
5. Нажмите **"Сохранить параметры"**

### Добавление расходов

1. Перейдите на вкладку **"Траты"**
2. Выберите **месяц и год** для планирования
3. Нажмите **"Добавить расход"**
4. Заполните форму:
   - Дата и время (по умолчанию — текущие)
   - Описание траты
   - Категория из списка
   - Сумма и валюта (EUR/UAH/BGN)
5. Нажмите **"Сохранить"**

### Просмотр бюджета

1. Перейдите на вкладку **"Бюджет"**
2. Выберите **период** (месяц/год) для просмотра
3. Используйте **фильтр по категориям**, чтобы увидеть только нужные категории
4. Изучите таблицу с **цветовой индикацией**:
   - 🟢 Зелёный — траты в пределах лимита
   - 🟡 Жёлтый — приближение к лимиту (>80%)
   - 🔴 Красный — превышение лимита
5. Проанализируйте **график** план vs факт
6. Оцените **итоги**: остаток и отложенные средства

### Обновление курсов валют

1. В верхней части экрана найдите блок **"Курсы валют"**
2. Нажмите **"Обновить курсы"** для автоматического обновления через Monobank API
3. Или измените курсы вручную и нажмите **"Сохранить курсы"**
4. Время последнего обновления и источник отображаются под курсами

### Индикатор подключения

В правом верхнем углу отображается статус подключения к серверу:

- **🟢 Зелёная галочка** — подключено к серверу, данные синхронизированы
- **⚠️ Жёлтый треугольник** — проблемы с подключением, работа в оффлайн режиме
- **💾 Дискета** — API отключен, работает только локальное хранение

**Наведите курсор** на иконку для детальной информации.
**Кнопка "🔄 Синхронизировать"** позволяет принудительно синхронизировать данные с сервером.

### Смена пароля

1. Нажмите на **⚙️ Настройки** в правом верхнем углу
2. Введите **текущий пароль**
3. Введите **новый пароль** (дважды для подтверждения)
4. Нажмите **"Сменить пароль"**
5. При успешной смене пароля вы останетесь в системе

## 🔒 Безопасность

### Защита данных

- **Пароль** — вход в приложение защищён паролем
- **SHA-256 хеширование** — пароль хранится в зашифрованном виде
- **API ключ** — все запросы к серверу требуют аутентификации
- **HTTPS** — все данные передаются по зашифрованному соединению
- **CORS** — ограничение источников запросов к API

### Рекомендации

1. **Смените пароль** по умолчанию сразу после первого входа
2. **Используйте сложный пароль** — комбинация букв, цифр и символов
3. **Не делитесь API ключом** — это даёт полный доступ к вашим данным
4. **Регулярно делайте резервные копии** — используйте функцию экспорта

### Утилиты для работы с паролем

В папке [docs/tools/](docs/tools/) доступны следующие утилиты:

- **[hash-password.html](docs/tools/hash-password.html)** — генератор SHA-256 хеша для пароля
- **[reset-password.html](docs/tools/reset-password.html)** — диагностика и сброс пароля на значение по умолчанию

### Хранение данных

#### Локально (в браузере)
```
localStorage
├─ budgetAppPasswordHash    # Хеш пароля (SHA-256)
├─ budgetAppData            # Категории и настройки
└─ budgetAppExpenses        # Все расходы
```

#### На сервере
```
/opt/budget_api/
├─ data.json                # Актуальные данные
└─ backups/                 # Резервные копии (30 дней)
   ├─ data_backup_20251021_120000.json
   ├─ data_backup_20251021_180000.json
   └─ ...
```

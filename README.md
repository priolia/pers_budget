## 🎯 О проекте

**Персональное бюджетирование** — это современное веб-приложение для эффективного управления личными финансами с поддержкой:
- 🌍 Нескольких валют (EUR, UAH, BGN)
- ☁️ Серверного хранения данных с автоматической синхронизацией
- 💾 Оффлайн режима с локальным сохранением
- 📊 Визуализации бюджета с помощью графиков
- 🔐 Защиты данных паролем

### ✨ Ключевые преимущества

- **Не потеряете данные** — автоматическое сохранение на сервер и резервное копирование
- **Работает везде** — доступ с любого устройства через браузер
- **Работает оффлайн** — продолжайте работать даже без интернета
- **Простота** — всё в одном интерфейсе, никаких сложных настроек
- **Безопасность** — данные защищены паролем и API ключом

### Режимы работы

#### 1. 🟢 Online режим (✅)
- Данные загружаются с сервера при запуске
- Все изменения автоматически сохраняются на сервер
- Локальная копия в браузере обновляется для оффлайн доступа

#### 2. 🟡 Offline режим (💾)
- Приложение работает с локальными данными из браузера
- Изменения сохраняются только локально
- При восстановлении связи данные синхронизируются

#### 3. 🔴 Проблемы подключения (⚠️)
- Отображается предупреждение
- Работа продолжается в оффлайн режиме
- Пользователь видит причину проблемы

## ☁️ Серверная часть (API)

### Обзор

Backend API обеспечивает:
- ✅ Централизованное хранение данных
- ✅ Синхронизацию между устройствами
- ✅ Автоматическое резервное копирование
- ✅ Безопасный доступ через HTTPS

### Архитектура Backend

```
/opt/budget_api/
├── app.py                 # Flask API сервер
├── config.py              # Конфигурация
├── requirements.txt       # Python зависимости
├── .env                   # Переменные окружения (секреты)
├── data.json             # Основные данные
├── backups/              # Автоматические резервные копии
│   └── data_backup_*.json
└── venv/                 # Виртуальное окружение Python
```

### API Endpoints

#### `GET /api/health`
Проверка работоспособности сервера

**Ответ:**
```json
{
  "status": "ok",
  "timestamp": "2025-10-21T12:00:00.123456",
  "version": "1.0.0"
}
```

#### `GET /api/data`
Получить все данные пользователя

**Заголовки:**
```
X-API-Key: your-api-key
```

**Ответ:**
```json
{
  "categories": [...],
  "expenses": [...],
  "settings": {
    "rateEURtoUAH": 41.5,
    "rateEURtoBGN": 1.96,
    "taxRate": 7.3,
    ...
  }
}
```

#### `POST /api/data`
Сохранить все данные

**Заголовки:**
```
Content-Type: application/json
X-API-Key: your-api-key
```

**Тело запроса:**
```json
{
  "categories": [...],
  "expenses": [...],
  "settings": {...}
}
```

**Ответ:**
```json
{
  "success": true,
  "message": "Данные успешно сохранены",
  "timestamp": "2025-10-21T12:00:00.123456"
}
```

#### `GET /api/export`
Экспортировать данные (скачать JSON файл)

**Заголовки:**
```
X-API-Key: your-api-key
```

**Ответ:**  
Файл `budget_export_YYYYMMDD_HHMMSS.json`

#### `GET /api/backups`
Получить список доступных резервных копий

**Заголовки:**
```
X-API-Key: your-api-key
```

**Ответ:**
```json
{
  "backups": [
    {
      "filename": "data_backup_20251021_120000.json",
      "date": "2025-10-21T12:00:00",
      "size": 12345
    }
  ]
}
```

### Развёртывание собственного сервера

Детальная инструкция по развёртыванию доступна в:
- 📘 **[РУКОВОДСТВО_ПО_УПРАВЛЕНИЮ_BUDGET_API.md](./РУКОВОДСТВО_ПО_УПРАВЛЕНИЮ_BUDGET_API.md)** — полное руководство
- 📄 **[DEPLOYMENT.md](./DEPLOYMENT.md)** — пошаговая инструкция для начинающих
- ⚡ **[QUICKSTART.md](./QUICKSTART.md)** — быстрый старт за 5 минут

**Краткая схема развёртывания:**

1. **Подготовка сервера**
   ```bash
   # Обновление системы
   sudo apt update && sudo apt upgrade -y
   
   # Установка зависимостей
   sudo apt install python3 python3-pip python3-venv nginx certbot python3-certbot-nginx
   ```

2. **Установка приложения**
   ```bash
   # Создание директории
   sudo mkdir -p /opt/budget_api
   cd /opt/budget_api
   
   # Создание виртуального окружения
   python3 -m venv venv
   source venv/bin/activate
   
   # Установка зависимостей
   pip install flask flask-cors python-dotenv
   ```

3. **Настройка переменных окружения**
   ```bash
   # Создание .env файла
   nano /opt/budget_api/.env
   
   # Добавьте ваши настройки:
   API_KEY=ваш-секретный-ключ
   ALLOWED_ORIGINS=https://ваш-домен.github.io
   ```

4. **Настройка Systemd сервиса**
   ```bash
   sudo nano /etc/systemd/system/budget-api.service
   ```

5. **Настройка Nginx + SSL**
   ```bash
   # Создание конфигурации Nginx
   sudo nano /etc/nginx/sites-available/budget-api
   
   # Активация конфигурации
   sudo ln -s /etc/nginx/sites-available/budget-api /etc/nginx/sites-enabled/
   
   # Получение SSL сертификата
   sudo certbot --nginx -d ваш-домен.duckdns.org
   ```

6. **Запуск сервиса**
   ```bash
   sudo systemctl daemon-reload
   sudo systemctl enable budget-api
   sudo systemctl start budget-api
   ```

### Управление сервером

```bash
# Проверка статуса
sudo systemctl status budget-api

# Перезапуск
sudo systemctl restart budget-api

# Просмотр логов
sudo journalctl -u budget-api -f

# Проверка работы API
curl https://ваш-домен.duckdns.org/api/health
```

## 📖 Использование

### Первый запуск

1. **Откройте приложение** в браузере
2. **Пароль по умолчанию**: `1234`
3. **Войдите в систему**
4. **Смените пароль** в разделе "Настройки" для безопасности

### Настройка бюджета

1. Перейдите на вкладку **"Справочник"**
2. Укажите ваш **доход в евро**
3. Настройте **лимиты ФОП и крипто** (если необходимо)
4. Отредактируйте **категории расходов**:
   - Измените существующие категории
   - Добавьте новые через кнопку "Добавить категорию"
   - Укажите лимиты в EUR или в % от дохода
5. Нажмите **"Сохранить параметры"**

### Добавление расходов

1. Перейдите на вкладку **"Траты"**
2. Выберите **месяц и год** для планирования
3. Нажмите **"Добавить расход"**
4. Заполните форму:
   - Дата и время (по умолчанию — текущие)
   - Описание траты
   - Категория из списка
   - Сумма и валюта (EUR/UAH/BGN)
5. Нажмите **"Сохранить"**
6. Расход автоматически сохранится на сервер (если онлайн)

### Просмотр бюджета

1. Перейдите на вкладку **"Бюджет"**
2. Выберите **период** (месяц/год) для просмотра
3. Изучите таблицу с категориями и расходами
4. Обратите внимание на **цветовую индикацию**:
   - 🟢 Зелёный — траты в пределах лимита
   - 🟡 Жёлтый — приближение к лимиту (>80%)
   - 🔴 Красный — превышение лимита
5. Проанализируйте **график** план vs факт
6. Оцените **итоги**: остаток и отложенные средства

### Обновление курсов валют

1. В верхней части экрана найдите блок **"Курсы валют"**
2. Нажмите **"Обновить курсы"** для автоматического обновления
3. Или измените курсы вручную и нажмите **"Сохранить курсы"**

### Индикатор подключения

В правом верхнем углу отображается статус подключения к серверу:

- **✅ Зелёная галочка** — подключено к серверу, данные синхронизированы
- **⚠️ Жёлтый треугольник** — проблемы с подключением, работа в оффлайн режиме
- **💾 Дискета** — API отключен, работает только локальное хранение

**Наведите курсор** на иконку для детальной информации.

## 🔒 Безопасность

### Защита данных

- **Пароль** — вход в приложение защищён паролем
- **SHA-256 хеширование** — пароль хранится в зашифрованном виде
- **API ключ** — все запросы к серверу требуют аутентификации
- **HTTPS** — все данные передаются по зашифрованному соединению
- **CORS** — ограничение источников запросов к API

### Рекомендации

1. **Смените пароль** по умолчанию сразу после первого входа
2. **Используйте сложный пароль** — комбинация букв, цифр и символов
3. **Не делитесь API ключом** — это даёт полный доступ к вашим данным
4. **Регулярно делайте резервные копии** — используйте функцию экспорта

### Хранение данных

#### Локально (в браузере)
```
localStorage
├─ budgetAppPasswordHash    # Хеш пароля (SHA-256)
├─ budgetAppData            # Категории и настройки
└─ budgetAppExpenses        # Все расходы
```

#### На сервере
```
/opt/budget_api/
├─ data.json                # Актуальные данные
└─ backups/                 # Резервные копии (30 дней)
   ├─ data_backup_20251021_120000.json
   ├─ data_backup_20251021_180000.json
   └─ ...
```

## 🛠️ Разработка

### Локальная разработка

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/priolia/pers_budget.git
   cd pers_budget
   ```

2. **Откройте index.html в браузере**
   ```bash
   # На Linux/Mac:
   open index.html
   
   # На Windows:
   start index.html
   ```

3. **Для разработки с локальным сервером:**
   ```bash
   python -m http.server 8000
   # Откройте http://localhost:8000
   ```

### Разработка Backend

1. **Установите зависимости**
   ```bash
   cd budget_api
   python3 -m venv venv
   source venv/bin/activate  # Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

2. **Создайте .env файл**
   ```bash
   cp .env.example .env
   # Отредактируйте .env с вашими настройками
   ```

3. **Запустите сервер**
   ```bash
   python app.py
   ```

4. **Протестируйте API**
   ```bash
   curl http://localhost:5000/api/health
   ```

### Структура кода

**index.html** — всё приложение в одном файле:
- `<style>` — весь CSS
- `<body>` — HTML структура
- `<script>` — весь JavaScript
  - Глобальные переменные
  - Функции авторизации
  - Функции расчётов
  - Функции интерфейса
  - Инициализация

**api.js** — модуль для работы с сервером:
- `BudgetAPI.loadData()` — загрузка данных
- `BudgetAPI.saveData()` — сохранение данных
- `BudgetAPI.checkHealth()` — проверка подключения
- `BudgetAPI.exportData()` — экспорт данных
- `BudgetAPI.sync()` — синхронизация

# 💰 Приложение для персонального бюджетирования

Веб-приложение для учета личных финансов с поддержкой трех валют (EUR, UAH, BGN).

## 🚀 [Открыть приложение](https://priolia.github.io/pers_budget/)


---

## 📱 Возможности

### Основное
- 💶 Учет расходов в трех валютах (EUR, UAH, BGN)
- 📊 Автоматический расчет бюджета
- 📈 Визуализация расходов (графики)
- 🔄 Автоматическая загрузка курсов валют
- 📅 Отслеживание расходов по месяцам
- 🎨 Цветовая индикация исполнения бюджета

### Безопасность
- 🔒 Защита паролем (SHA-256)
- 💾 Локальное хранение данных
- 🔐 Смена пароля

### Удобство
- 📱 Адаптивный дизайн (работает на телефоне/планшете)
- 💾 Экспорт данных в JSON
- ⚙️ Гибкие настройки категорий
- 🌐 Работает офлайн (после первой загрузки)

---

## 🎯 Как использовать

### Первый вход
1. Откройте ссылку на приложение
2. Введите пароль: `budget2025`
3. Смените пароль (Настройки → Смена пароля)

### Настройка
1. Перейдите в **Справочник**
2. Укажите свой доход в евро
3. Настройте категории расходов
4. Установите лимиты

### Добавление расходов
1. Перейдите во вкладку **Траты**
2. Нажмите "Добавить расход"
3. Заполните дату, описание, категорию, сумму
4. Нажмите 💾 Сохранить

### Просмотр бюджета
1. Вкладка **Бюджет**
2. Выберите месяц и год
3. Смотрите сводку и графики

## 🔐 Безопасность

### Что хранится
- ✅ Пароль (хеш SHA-256) - в localStorage браузера
- ✅ Ваши расходы - в localStorage браузера
- ✅ Настройки - в localStorage браузера

### Что НЕ хранится
- ❌ Ничего на сервере
- ❌ Ничего в облаке
- ❌ Ничего не отправляется никуда

### Важно
- Данные хранятся локально в каждом браузере отдельно
- При очистке кеша данные могут пропасть
- **Регулярно делайте экспорт данных!** (Настройки → Экспорт)

## 🐛 Известные ограничения

1. **Нет синхронизации между устройствами**
   - Данные хранятся локально в каждом браузере
   - Решение: Экспорт/импорт данных вручную

2. **localStorage может очиститься**
   - При очистке кеша браузера
   - Решение: Регулярный экспорт данных

3. **Нет импорта данных**
   - Можно экспортировать, но пока нельзя импортировать
   - Планируется в следующей версии

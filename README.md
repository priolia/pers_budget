# 💰 Персональное бюджетирование

Веб-приложение для учёта личных финансов. Открытие: **[priolia.github.io/pers_budget](https://priolia.github.io/pers_budget/)**

> Версия 2.4 (май 2026). Личный проект, не предназначен для широкого использования.

---

## Что это

Личный бюджет на месяц с привязкой к датам зарплаты (период «25-го одного месяца — 24-го следующего», настраивается).

- **Категории** с лимитами в евро и процентами от дохода
- **Учёт трат** в EUR и UAH (BGN убран — Болгария с 01.01.2026 в еврозоне)
- **Карточки итогов**: сколько потрачено, сколько ещё запланировано, сколько свободно, сколько в день можно тратить
- **Курсы валют** автоматически с Monobank API (среднее между rateBuy и rateSell), показывается дата от ЕЦБ
- **Сервер на HostHatch** для синхронизации между устройствами
- **Защита паролем** на входе (SHA-256), API-ключ для запросов к серверу

## Стек

- **Фронтенд:** ванильный JS (ES Modules), HTML, CSS. Chart.js для графиков. Без сборки.
- **Бэкенд:** Flask + SQLite на Ubuntu, Nginx как реверс-прокси, Let's Encrypt для HTTPS.
- **Хостинг:** GitHub Pages (фронтенд) + HostHatch (API).

## Возможности (актуально для v2.4)

### Период
- Кастомный месяц — настраивается день начала (например, 25-е). Тогда «период» = с 25-го по 24-е следующего месяца.
- Селектор периода динамически показывает: **1 прошлый + текущий + 12 будущих**. Никаких захардкоженных диапазонов — список сам перестраивается каждый день.
- Архивные периоды (с тратами, старше «прошлого») — отдельной группой «📦 Архив» в том же селекторе.

### Категории
- Иконки (emoji) — отображаются везде, где упоминается категория. При создании новой категории — автоматическое предложение по словарю (например, «Аптека…» → 💊).
- Порядок управляется стрелками ↑↓ в Справочнике. Автопересохранение на сервер.
- Категория по умолчанию для новых трат — выбирается в Настройках.

### Карточки итогов на вкладке «Бюджет»
**Сверху** (три главные карточки):
- **До конца периода** — N дней + сколько ещё свободно + «можно в день» (свободные/дней)
- **% исполнения бюджета** — Σ факт / Σ план
- **План в день** — Σ запланированных трат / дней (сколько в день будет уходить на обязательные)

**Под таблицей** (второстепенные): Доход, Потрачено, Запланировано ещё, Перерасход (показывается только если есть), Отложено.

### Таблица бюджета
Колонки: Категория, План, Факт, % исполнения, Остаток в Плане, **€/день** (остаток / оставшиеся дни).

«Свободно» отдельной карточкой не показывается — цифра попадает в «До конца периода».

### Таблица трат
Колонки: Описание, Категория, Сумма, Валюта, Σ план, Бюджет реф €, Бюджет реф %, Действия, Дата. Дата перенесена в конец — она редко правится.

На мобиле первая колонка (Описание) залипает при горизонтальном скролле, длинные описания обрезаются троеточием.

## Управление

### Локально на компе

Никакого билда не нужно. Открой `index.html` в браузере — заработает (без сервера будет ругаться на API, но интерфейс посмотреть можно).

### Серверная часть

Подробности в `docs/РУКОВОДСТВО_ПО_УПРАВЛЕНИЮ_BUDGET_API.md`. Если коротко — на сервере крутится `systemd`-сервис, рестарт `sudo systemctl restart budget-api`, логи `journalctl -u budget-api -f`.

### Утилиты для пароля

- Сгенерировать хэш SHA-256 нового пароля — открой [docs/tools/hash-password.html](https://priolia.github.io/pers_budget/docs/tools/hash-password.html)
- Сбросить пароль локально (если забыла) — [docs/tools/reset-password.html](https://priolia.github.io/pers_budget/docs/tools/reset-password.html)

### Деплой

`main` автоматически разворачивается на GitHub Pages. Изменения подхватываются в течение 1-3 минут после пуша. Иногда нужен Ctrl+Shift+R, чтобы пробить кеш браузера.

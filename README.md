## 🎯 О проекте

**Персональное бюджетирование** — это веб-приложение для эффективного управления личными финансами с поддержкой нескольких валют (EUR, UAH, BGN). Приложение работает полностью в браузере без необходимости установки и позволяет:

- 📊 Отслеживать доходы и расходы по категориям
- 💱 Автоматически конвертировать валюты по актуальным курсам
- 📈 Визуализировать бюджет с помощью графиков
- 🔐 Защищать данные паролем
- 💾 Хранить все локально в браузере

**Особенности:**
- ✅ Нет серверной части — всё работает в браузере
- ✅ Автономная работа (кроме обновления курсов)
- ✅ Адаптивный дизайн для мобильных устройств
- ✅ Экспорт данных в JSON

## ✨ Возможности

### 📊 Вкладка "Бюджет"

- **Сводная таблица** с планом и фактом по каждой категории
- **Цветовая индикация** расходов:
  - 🟢 Зеленый — до 50% от бюджета
  - 🟡 Желтый — 50-90% от бюджета
  - 🟠 Оранжевый — 90-100% от бюджета
  - 🔴 Красный (зачеркнутый) — перерасход >100%
- **Интерактивный график** сравнения плана и факта (Chart.js)
- **Итоги по периоду**:
  - Общий доход
  - Фактические расходы
  - Планируемые расходы
  - Отложенные средства в EUR и UAH

### 💸 Вкладка "Траты"

- **Добавление расходов** с датой, описанием, категорией и суммой
- **Поддержка трех валют**: EUR, UAH, BGN
- **Автоматическая конвертация** введенной суммы во все валюты
- **Справочная информация** при добавлении:
  - Оставшийся лимит по категории
  - Референсные значения в гривнах
- **Управление записями**: редактирование и удаление расходов
- **Экспорт** расходов за выбранный период в JSON
- **Фильтр по периодам** — просмотр трат за конкретный месяц/год

### 📚 Вкладка "Справочник"

- **Параметры дохода**:
  - Ввод дохода в евро
  - Настройка ставки налога (по умолчанию 7.3%)
- **Лимиты**:
  - Лимит ФОП (для расчета налога)
  - Лимит крипто-дохода
- **Категории расходов**:
  - Создание, редактирование и удаление категорий
  - Установка лимита в евро или в процентах от дохода
  - Автоматический расчет сумм в UAH и BGN
- **Сводная информация**:
  - Общий бюджет в трех валютах
  - Расчет налога с ФОП
  - Референсные суммы для всех категорий

### ⚙️ Вкладка "Настройки"

- **Смена пароля** с подтверждением
- **Экспорт всех данных** (категории, расходы, настройки) в JSON
- **Очистка всех данных** с двойным подтверждением

### 💱 Курсы валют

- **Автоматическое обновление** курсов через API
- **Отображение актуальных курсов**:
  - EUR → UAH
  - EUR → BGN
  - BGN → UAH (расчетный)
- **Дата последнего обновления**
- **Пересчет всех сумм** при изменении курсов

## 📖 Использование

### Первый запуск

1. **Откройте приложение** — вы увидите экран входа
2. **Пароль по умолчанию**: `1234`
3. **Войдите в систему**
4. **Смените пароль** в разделе "Настройки" для безопасности

### Настройка бюджета

1. Перейдите на вкладку **"Справочник"**
2. Укажите ваш **доход в евро**
3. Настройте **лимиты ФОП и крипто** (если необходимо)
4. Отредактируйте **категории расходов**:
   - Измените существующие категории
   - Добавьте новые через кнопку "Добавить категорию"
   - Укажите лимиты в EUR или в % от дохода
5. Нажмите **"Сохранить параметры"**

### Добавление расходов

1. Перейдите на вкладку **"Траты"**
2. Выберите **месяц и год** для планирования
3. Нажмите **"Добавить расход"**
4. Заполните форму:
   - Дата и время (по умолчанию — текущие)
   - Описание траты
   - Категория из списка
   - Сумма и валюта (EUR/UAH/BGN)
5. Нажмите **"Сохранить"**
6. Расход автоматически появится в таблице и обновит бюджет

### Просмотр бюджета

1. Перейдите на вкладку **"Бюджет"**
2. Выберите **период** (месяц/год) для просмотра
3. Изучите таблицу с категориями и расходами
4. Обратите внимание на **цветовую индикацию**
5. Проанализируйте **график** план vs факт
6. Оцените **итоги**: остаток и отложенные средства

### Обновление курсов валют

1. В верхней части экрана найдите блок **"Курсы валют"**
2. Нажмите кнопку **"Обновить курсы"**
3. Дождитесь обновления (требуется интернет)
4. Все суммы пересчитаются автоматически

### Экспорт данных

**Экспорт расходов за период:**
1. Вкладка "Траты" → кнопка "Экспортировать"
2. Скачается JSON-файл с расходами за выбранный месяц

**Экспорт всех данных:**
1. Вкладка "Настройки" → "Экспортировать все данные"
2. Скачается полный бэкап приложения в JSON

## 🔐 Безопасность

### Хранение паролей

- Пароль **не хранится в открытом виде**
- Используется **SHA-256 хеширование**
- Хеш сохраняется в `localStorage`
- При входе введенный пароль хешируется и сравнивается с сохраненным

### Хранение данных

- Все данные хранятся **только в вашем браузере**
- Данные **не передаются на серверы**
- При очистке данных браузера всё удаляется
- Рекомендуется регулярно **делать бэкапы** через экспорт

### Рекомендации

- ⚠️ **Смените пароль** при первом запуске
- 💾 **Регулярно экспортируйте данные**
- 🔒 **Не используйте на публичных компьютерах** без выхода
- 📱 **Используйте HTTPS** при размещении на хостинге

## 🔧 Разработка

### Структура кода

Весь код находится в одном файле `index.html`:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <style>/* Весь CSS здесь */</style>
</head>
<body>
    <!-- Весь HTML здесь -->
    <script>// Весь JavaScript здесь</script>
</body>
</html>
```

### Основные JavaScript-функции

**Авторизация:**
- `hashPassword()` — хеширование SHA-256
- `login()` — вход в систему
- `changePassword()` — смена пароля

**Данные:**
- `saveData()` — сохранение в localStorage
- `loadData()` — загрузка из localStorage
- `getAllExpenses()` — получение всех расходов
- `getExpensesForPeriod()` — расходы за период

**Расчеты:**
- `calculateCategoryAmounts()` — расчет сумм категорий
- `calculateReferenceAmounts()` — референсные суммы
- `updateBudgetSummary()` — обновление сводки

**Интерфейс:**
- `renderCategoriesTable()` — отрисовка категорий
- `renderExpensesTable()` — отрисовка расходов
- `createBudgetChart()` — создание графика
- `showTab()` — переключение вкладок

### Модификация кода

1. Откройте `index.html` в любом редакторе кода
2. Найдите нужный раздел:
   - CSS — в `<style>` тегах
   - HTML — в `<body>` теге
   - JavaScript — в `<script>` теге
3. Внесите изменения
4. Сохраните файл
5. Откройте в браузере для тестирования

### API курсов валют

Приложение использует публичный API для получения курсов:

```javascript
const API_URL = 'https://api.exchangerate.host/latest?base=EUR&symbols=UAH,BGN';
```

Если этот API недоступен, можно заменить на другой в функции `updateExchangeRates()`.

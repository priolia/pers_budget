# ⚡ Быстрый запуск API v2.0

## 🔴 Решение вашей проблемы (ModuleNotFoundError: No module named 'flask')

Вы получили эту ошибку потому что запускали `python3 app_v2.py` напрямую.
Нужно использовать **виртуальное окружение** где установлен Flask!

### Вариант 1: Быстрое решение (вручную)

```bash
# 1. Остановите старый процесс (используйте ПРАВИЛЬНЫЙ PID!)
kill 2922830  # ← это PID из вашего вывода "ps aux"

# 2. Запустите через ВИРТУАЛЬНОЕ ОКРУЖЕНИЕ
nohup /opt/budget_api/venv/bin/python /opt/budget_api/app_v2.py > /opt/budget_api/app_v2.log 2>&1 &

# 3. Проверьте
curl http://localhost:5000/api/health
# Должно вернуть: {"status":"ok", ..., "version":"2.0.0"}

# 4. Смотрите логи
tail -f /opt/budget_api/app_v2.log
```

---

### Вариант 2: Использование скрипта (рекомендуется)

Скопируйте файл `manage_api.sh` на сервер и используйте его:

```bash
# Скопируйте скрипт на сервер
scp manage_api.sh your_user@your_server:/opt/budget_api/

# На сервере:
cd /opt/budget_api
chmod +x manage_api.sh

# Используйте скрипт:
./manage_api.sh stop      # Остановить старый API
./manage_api.sh start     # Запустить новый API v2.0
./manage_api.sh status    # Проверить статус
./manage_api.sh logs      # Посмотреть логи
./manage_api.sh restart   # Перезапустить API
```

## ✅ Проверка что всё работает

После запуска выполните:

```bash
# 1. Проверка версии API (должно быть 2.0.0!)
curl http://localhost:5000/api/health

# 2. Проверка что старый API остановлен
ps aux | grep "python.*app.py"
# Не должно быть процессов!

# 3. Проверка что новый API запущен
ps aux | grep "python.*app_v2.py"
# Должен быть 1 процесс с venv/bin/python

# 4. Проверка логов
tail -n 50 /opt/budget_api/app_v2.log
# Не должно быть ошибок!
```

## 🆘 Если не работает

### Проблема: "kill: No such process"

Сначала найдите правильный PID:
```bash
ps aux | grep "python.*app"
```

### Проблема: Flask всё равно не найден

Проверьте виртуальное окружение:
```bash
# Проверьте что venv существует
ls -la /opt/budget_api/venv/bin/python

# Проверьте что Flask установлен
/opt/budget_api/venv/bin/pip list | grep -i flask
```

Если Flask не установлен:
```bash
cd /opt/budget_api
source venv/bin/activate
pip install flask flask-cors python-dotenv
deactivate
```

### Проблема: API запускается но падает сразу

Смотрите логи:
```bash
tail -f /opt/budget_api/app_v2.log
```

Частые причины:
- Порт 5000 занят → измените порт в app_v2.py
- Нет файла .env → создайте с API_KEY
- Нет прав на папку data → `chmod 755 /opt/budget_api/data`

## 📦 Часть 1: Обновление серверной части (Backend)

### Шаг 1.1: Подключитесь к серверу

1. Откройте программу для подключения к серверу (например, PuTTY или Terminal)
2. Подключитесь к вашему серверу используя SSH

```
ssh ваш_пользователь@ваш_сервер
```

Например:
```
ssh priolia@priolia-budget.duckdns.org
```

### Шаг 1.2: Перейдите в папку с API

```bash
cd budget_api
```

### Шаг 1.3: Остановите текущий API сервер

```bash
pkill -f "python.*app.py"
```

Или если вы используете systemd:
```bash
sudo systemctl stop budget-api
```

### Шаг 1.4: Создайте резервную копию старого файла

```bash
cp app.py app.py.backup
```

### Шаг 1.5: Загрузите новый файл app_v2.py на сервер

**Вариант А: Если вы работаете локально на сервере**

Файл `app_v2.py` уже находится в репозитории на ветке `claude/refactor-budget-app-v2-011CUNok7Vkv3yXtMqoAboZS`.

Сделайте git pull:
```bash
cd ~/budget_api
git pull origin claude/refactor-budget-app-v2-011CUNok7Vkv3yXtMqoAboZS
```

**Вариант Б: Если загружаете через FTP/SCP**

Скачайте файл `app_v2.py` из репозитория на свой компьютер, затем загрузите на сервер:

```bash
scp budget_api/app_v2.py ваш_пользователь@ваш_сервер:~/budget_api/
```

### Шаг 1.6: Запустите новый API сервер

```bash
cd ~/budget_api
python3 app_v2.py
```

Вы должны увидеть:
```
==================================================
🚀 Запуск Budget API Server v2.0
==================================================
Host: 0.0.0.0
Port: 5000
...
```

Если всё работает, нажмите `Ctrl+C` чтобы остановить, и запустите в фоновом режиме:

```bash
nohup python3 app_v2.py > api.log 2>&1 &
```

Или настройте как systemd сервис:

```bash
sudo nano /etc/systemd/system/budget-api.service
```

Содержимое файла:
```ini
[Unit]
Description=Budget API v2.0
After=network.target

[Service]
Type=simple
User=ваш_пользователь
WorkingDirectory=/home/ваш_пользователь/budget_api
ExecStart=/usr/bin/python3 /home/ваш_пользователь/budget_api/app_v2.py
Restart=always

[Install]
WantedBy=multi-user.target
```

Затем:
```bash
sudo systemctl daemon-reload
sudo systemctl enable budget-api
sudo systemctl start budget-api
sudo systemctl status budget-api
```

```bash

cp api.js api.js.backup
```

### Шаг 2.2: Загрузите новые файлы

Из ветки `claude/refactor-budget-app-v2-011CUNok7Vkv3yXtMqoAboZS` скопируйте на сервер следующие папки и файлы:

**Папки:**

**Файлы:**
- `js/config.js`
- `js/dataManager.js`
- `js/api.js` (новая версия)
- `js/sync.js`

### Шаг 2.3: Обновите index.html

В конец файла `index.html` (перед закрывающим тегом `</body>`), добавьте:

**Важно**: Строка `type="module"` обязательна!

Откройте файл `js/config.js` и убедитесь, что настройки API правильные:

```javascript
    KEY: 'BdgtAPI_7k9mX2pL5nQ8wR4vY6zT3hJ0sF1dG',      // ВАШ API ключ
```

## 🔄 Часть 4: Миграция данных (ВАЖНО!)

После установки необходимо мигрировать старые данные на новый формат с ID.

### Вариант А: Автоматическая миграция через консоль

1. Откройте консоль браузера (F12)
2. Введите команду:

```javascript
await BudgetApp.migrate()
```

3. Следуйте инструкциям на экране
4. После миграции перезагрузите страницу

### Вариант Б: Миграция через кнопку (если добавите в настройки)

1. Откройте вкладку **Настройки**
2. Найдите секцию **Обслуживание**
3. Нажмите кнопку **Мигрировать данные на новый формат**
4. Подтвердите действие
5. Дождитесь завершения

### Вариант В: Миграция через импорт

1. **Экспортируйте** все данные из старой версии (кнопка "Экспортировать данные")
2. Сохраните файл `budget_export_*.json`
3. В новой версии нажмите кнопку **Импортировать данные**
4. Выберите сохраненный файл
5. Выберите стратегию: **Заменить все данные**
6. Подтвердите импорт

## 🎨 Часть 5: Дополнительные настройки (Опционально)

### Настройка кастомного периода

1. Откройте вкладку **Настройки**
2. Найдите **День начала периода**
3. Измените значение (от 1 до 28)
4. Нажмите **Сохранить**

Теперь ваш период будет начинаться с выбранного дня каждого месяца!

### Обновление курсов валют

1. Откройте вкладку **Настройки**
2. Найдите секцию **Курсы валют**
3. Нажмите **🔄 Обновить курсы с Monobank**

Или через консоль:
```javascript
await BudgetApp.updateRates()
```

### Импорт данных из файла

1. Откройте вкладку **Настройки**
2. Найдите секцию **Данные**
3. Нажмите **📥 Импортировать данные из файла**
4. Выберите JSON файл с данными
5. Выберите стратегию импорта:
   - **Объединить** - добавить к существующим данным
   - **Заменить** - удалить все и загрузить из файла
6. Подтвердите

## 🐛 Решение проблем

### Проблема: "API недоступен"

**Решение:**
1. Проверьте что сервер запущен: `sudo systemctl status budget-api`
2. Проверьте логи: `tail -f ~/budget_api/api.log`
3. Проверьте настройки в `js/config.js`

### Проблема: "Ошибка загрузки модулей"

**Решение:**
1. Убедитесь что в `index.html` есть `type="module"`
2. Проверьте что все файлы `.js` загружены на сервер
3. Откройте консоль браузера и посмотрите ошибки
4. Проверьте что сервер отдает `.js` файлы с правильным MIME типом

### Проблема: "Данные не сохраняются"

**Решение:**
1. Выполните миграцию данных (см. Часть 4)
2. Проверьте что API сервер v2.0 запущен
3. Проверьте права на запись в папке `budget_api`

### Проблема: "Старые данные пропали"

**Не паникуйте!** Данные в бэкапах:

1. На сервере перейдите в папку: `cd ~/budget_api/backups`
2. Найдите последний бэкап: `ls -lht | head`
3. Восстановите: `cp backups/data_backup_*.json data.json`

Быстрый старт для развёртывания API сервера за 5 минут.

### [РУКОВОДСТВО_ПО_УПРАВЛЕНИЮ_BUDGET_API.md](./РУКОВОДСТВО_ПО_УПРАВЛЕНИЮ_BUDGET_API.md)

- Запуск и остановка сервера

- Решение проблем
- Обновление приложения

## 🔧 Утилиты и инструменты

Папка [tools/](./tools/) содержит вспомогательные HTML инструменты:

### [hash-password.html](./tools/hash-password.html)
Генератор SHA-256 хеша для пароля. Используется для:
- Создания нового хеша пароля
- Проверки корректности существующего хеша

### [reset-password.html](./tools/reset-password.html)
Утилита для диагностики и сброса пароля. Позволяет:
- Просмотреть текущий хеш пароля
- Проверить корректность пароля
- Сбросить пароль на значение по умолчанию

### [index_v1.html](./tools/index_v1.html)
Старая версия приложения (v1.0) для справки и сравнения.

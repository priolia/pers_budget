# 🚀 Пошаговая инструкция по развертыванию

Эта инструкция покажет как настроить серверную часть для хранения данных вашего бюджетного приложения.

---

## 📋 Что вам понадобится

- ✅ Доступ к серверу через WinSCP (у вас есть)
- ✅ IP адрес вашего сервера
- ✅ 15-20 минут времени

---

## 🎯 Шаг 1: Загрузить файлы на сервер

### 1.1 Откройте WinSCP и подключитесь к серверу

Вы уже это умеете (загружали бота) 😊

### 1.2 Загрузите папку budget_api

В WinSCP:
1. На **левой панели** (ваш компьютер) найдите папку `pers_budget/budget_api`
2. На **правой панели** (сервер) перейдите в домашнюю директорию (обычно `/home/ваш_username`)
3. **Перетащите** папку `budget_api` с левой панели на правую

Должна появиться папка на сервере:
```
/home/ваш_username/budget_api/
├── app.py
├── config.py
├── requirements.txt
├── .env
└── backups/
```

1. Найдите файл `budget_api/.env` на сервере


### 4.3 Сохраните файл

Нажмите `Ctrl+S` или выберите **File** → **Save**

Он понадобится в следующем шаге!

## 🌐 Шаг 5: Настроить клиентскую часть

### 5.1 Откройте файл api.js

На вашем компьютере откройте файл `pers_budget/api.js` в любом текстовом редакторе (Notepad, Notepad++, VS Code и т.д.)

### 5.2 Найдите эти строки (примерно строки 15-18):

```javascript
// URL вашего API сервера (замените YOUR_SERVER_IP на IP вашего сервера)
API_BASE_URL: 'http://YOUR_SERVER_IP:5000/api',

// API ключ (должен совпадать с .env файлом на сервере)
API_KEY: 'my-secret-budget-key-2025',
```

### 5.3 Измените на ваши данные:

```javascript
// Замените 123.45.67.89 на IP вашего сервера
API_BASE_URL: 'http://123.45.67.89:5000/api',

// Замените на тот же ключ что в .env на сервере!
API_KEY: 'ваш-секретный-ключ-который-никто-не-угадает-12345',
```

**ВАЖНО:** API_KEY должен быть **ТОЧНО** таким же как в .env на сервере!

### 5.4 Сохраните файл

## 🚀 Шаг 6: Настроить автозапуск сервера

Чтобы сервер запускался автоматически при перезагрузке сервера:

### 6.1 Создайте файл сервиса

В консоли выполните (замените `USERNAME` на ваше имя пользователя на сервере):

```bash
sudo nano /etc/systemd/system/budget-api.service
```

Введите пароль если попросит.

### 6.2 Вставьте этот текст (замените USERNAME):

```ini
[Unit]
Description=Budget API Server
After=network.target

[Service]
Type=simple
User=USERNAME
WorkingDirectory=/home/USERNAME/budget_api
Environment="PATH=/usr/bin:/usr/local/bin"
ExecStart=/usr/bin/python3 /home/USERNAME/budget_api/app.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

**ВАЖНО:** Замените `USERNAME` на ваше имя пользователя (в 3 местах!)

### 6.3 Сохраните файл

1. Нажмите `Ctrl+X`
2. Нажмите `Y` (да, сохранить)
3. Нажмите `Enter`

### 6.4 Активируйте сервис

Выполните по очереди:

```bash
sudo systemctl daemon-reload
sudo systemctl enable budget-api
sudo systemctl start budget-api
```

### 6.5 Проверьте что все работает

```bash
sudo systemctl status budget-api
```

Должны увидеть:
```
● budget-api.service - Budget API Server
   Active: active (running) since ...
```

Если видите `active (running)` - отлично! ✅

Нажмите `Q` чтобы выйти.

## 🎯 Частые вопросы

### ❓ Индикатор показывает ⚠️ (оффлайн)

**Проверьте:**

1. Сервер запущен?
   ```bash
   sudo systemctl status budget-api
   ```

2. Правильный IP в `api.js`?
   ```javascript
   API_BASE_URL: 'http://123.45.67.89:5000/api',
   ```

3. Порт 5000 открыт?
   ```bash
   sudo ufw allow 5000
   ```

### ❓ Ошибка "API ключ неверный"

**Решение:**

API_KEY в `api.js` должен **ТОЧНО** совпадать с API_KEY в `.env` на сервере!

Проверьте оба файла.

### ❓ Сервер перестал работать после перезагрузки

**Решение:**

Проверьте статус:
```bash
sudo systemctl status budget-api
```

Если не активен:
```bash
sudo systemctl start budget-api
```

### ❓ Как посмотреть логи сервера?

```bash
sudo journalctl -u budget-api -f
```

Нажмите `Ctrl+C` чтобы выйти.

### ❓ Где находятся бэкапы?

```bash
ls -lh /home/USERNAME/budget_api/backups/
```

### ❓ Как скачать бэкап?

В WinSCP перейдите в папку `budget_api/backups/` и скачайте нужный файл.

### ❓ Хочу вернуться к локальному хранению

Откройте `api.js` и измените:

```javascript
USE_API: false,  // Было: true
```

## 🛟 Если ничего не работает

1. **Проверьте логи сервера:**
   ```bash
   sudo journalctl -u budget-api -n 50
   ```

2. **Проверьте что сервер слушает порт:**
   ```bash
   sudo netstat -tulpn | grep 5000
   ```

3. **Попробуйте перезапустить:**
   ```bash
   sudo systemctl restart budget-api
   ```

4. **Проверьте права на файлы:**
   ```bash
   ls -la /home/USERNAME/budget_api/
   ```

5. **Напишите мне** если ничего не помогает! 😊

## 📊 Полезные команды

### Управление сервисом

```bash
# Запустить
sudo systemctl start budget-api

# Остановить
sudo systemctl stop budget-api

# Перезапустить
sudo systemctl restart budget-api

# Статус
sudo systemctl status budget-api

# Посмотреть логи
sudo journalctl -u budget-api -f
```

### Резервное копирование

```bash
# Создать ручной бэкап
cp /home/USERNAME/budget_api/data.json /home/USERNAME/budget_api/backups/manual_$(date +%Y%m%d).json

# Посмотреть все бэкапы
ls -lh /home/USERNAME/budget_api/backups/

# Скачать бэкап (через WinSCP или scp)
```

### Обновление

Если вы изменили код `app.py` или `config.py`:

```bash
cd /home/USERNAME/budget_api
sudo systemctl restart budget-api
```

## 🔧 API Эндпоинты

### GET /api/health
Проверка работоспособности сервера

**Ответ:**
```json
{
  "status": "ok",
  "timestamp": "2025-10-21T12:00:00",
  "version": "1.0.0"
}
```

### GET /api/data
Получить все данные

**Заголовки:**
```
X-API-Key: your-api-key
```

**Ответ:**
```json
{
  "categories": [...],
  "expenses": [...],
  "settings": {...}
}
```

### POST /api/data
Сохранить все данные

**Заголовки:**
```
Content-Type: application/json
X-API-Key: your-api-key
```

**Тело запроса:**
```json
{
  "categories": [...],
  "expenses": [...],
  "settings": {...}
}
```

**Ответ:**
```json
{
  "success": true,
  "message": "Данные успешно сохранены",
  "timestamp": "2025-10-21T12:00:00"
}
```

### GET /api/export
Экспортировать данные (скачать JSON)

**Заголовки:**
```
X-API-Key: your-api-key
```

**Ответ:**
Скачивание файла `budget_export_YYYYMMDD_HHMMSS.json`

### GET /api/backups
Получить список доступных бэкапов

**Заголовки:**
```
X-API-Key: your-api-key
```

**Ответ:**
```json
{
  "backups": [
    {
      "filename": "data_backup_20251021_120000.json",
      "date": "2025-10-21T12:00:00",
      "size": 12345
    }
  ]
}
```

## 🔐 Безопасность

### API Ключ
- Простая аутентификация через заголовок `X-API-Key`
- Ключ задается в `.env` файле на сервере
- Тот же ключ прописывается в `api.js` на клиенте

### CORS
- Настроен для работы только с `priolia.github.io`
- Запросы с других доменов блокируются

### Бэкапы
- Автоматическое создание при каждом сохранении
- Хранение 30 дней (настраивается)
- Автоматическая очистка старых копий

---

## 🔄 Режимы работы

### 1. Online (✅)
- Все данные загружаются с сервера
- Все изменения сохраняются на сервер
- Копия хранится в localStorage для оффлайн работы

### 2. Offline (⚠️)
- Данные загружаются из localStorage
- Изменения сохраняются только локально
- При восстановлении связи - автосинхронизация

### 3. Local only (💾)
- API отключен в настройках (`USE_API: false`)
- Работа полностью локально как раньше
- Для тестирования или если не нужен сервер

### Требования к серверу:

- Python 3.6+

## 🛠 Техническая информация

### Технологии:

**Сервер:**
- Flask 3.0.0 (Python web framework)
- Flask-CORS (Cross-Origin Resource Sharing)
- python-dotenv (Управление переменными окружения)
- SQLite через JSON (простое файловое хранилище)

**Клиент:**
- Vanilla JavaScript (без фреймворков)
- Fetch API (HTTP запросы)
- localStorage (локальный кэш)
